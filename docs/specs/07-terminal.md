# 07 — 내장 터미널

## 역할

실제 pty 기반 터미널. 에이전트가 명령어를 실행하고, 사용자도 직접 사용.

## 위치

- **Spec 패널 하단** 고정 (현재 구현 위치 유지)
- 높이 조절 가능 (드래그 리사이즈)
- `⌘\`` 로 토글

## 기능 명세

### 기본 터미널
- node-pty 기반 실제 PTY 프로세스
- 색상 ANSI 지원
- 스크롤 히스토리
- 탭 여러 개 지원 (`+` 버튼으로 추가)

### 에이전트 명령 실행
- 에이전트가 `run-command` 도구 호출 시 터미널에 실행
- 실행 중인 명령어가 대화 패널에도 표시
- 결과(stdout/stderr)를 에이전트에게 피드백

### @ 멘션 참조
- 터미널 세션을 `@터미널명`으로 대화창에서 참조 가능
- 터미널 출력을 에이전트 컨텍스트로 주입

### Setup 스크립트
- 프로젝트별 시작 명령어 설정 (예: `npm run dev`)
- Space 열릴 때 자동 실행

## 현재 구현 상태

| 항목 | 상태 |
|------|------|
| 터미널 UI (정적 표시) | ✓ (가짜) |
| 실제 PTY 터미널 | ❌ (`terminal.ts` IPC는 있음) |
| 에이전트 명령 연동 | ❌ |
| 탭 지원 | ❌ |
| @ 멘션 참조 | ❌ |

## 구현 방법

```typescript
// electron/ipc/terminal.ts — node-pty 이미 구현됨
// SpecPanel 하단 TerminalBlock을 실제 xterm.js로 교체
// IPC: terminal:create → terminal:write → terminal:data (스트리밍)
```

## 단축키

| 단축키 | 기능 |
|--------|------|
| `⌘\`` | 터미널 패널 토글 |
| `⌘T` | 새 터미널 탭 |
